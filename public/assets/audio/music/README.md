# THE SEVEN HELLGATES — Soundtrack & Audio Asset Registry

This directory contains the music tracks for *THE SEVEN HELLGATES*.

## 1. Main Theme
- **`seven_hellgates_awakening_theme.wav`**
  - **Purpose**: Main Menu Awakening Theme & Prelude.
  - **Length**: ~48 seconds, seamless loopable.
  - **Style**: Dark-fantasy orchestral composition with low strings, brass horns, dark choir, and slow war drums.
  - *Note*: If this file is present in this folder, the game's AudioManager loads and plays it automatically with smooth crossfading. When absent, the Web Audio engine provides a procedural cinematic synth fallback.

## 2. Exploration & Ambience Themes
- **`limbo_exploration_theme.wav`**
  - **Realm**: Realm I (Limbo).
  - **Style**: Deep ambient drones (55Hz A minor), distant choir textures, low orchestral cello/bass ostinato, haunting bells, slow cinematic percussion.
- **`realm_2_gluttony_ambient.wav`** (G minor, fleshy pulses, viscous low-frequency resonance).
- **`realm_3_greed_ambient.wav`** (C minor, gilded metallic resonance, chimes).
- **`realm_4_wrath_ambient.wav`** (F minor, volcanic rumble, subterranean sub-bass).
- **`realm_5_heresy_ambient.wav`** (G# minor, dark liturgical choir, ominous organ drone).
- **`realm_6_violence_ambient.wav`** (E minor, war drum undertone, tense strings).
- **`realm_7_sovereign_ambient.wav`** (D minor, celestial cosmic void, ethereal dissonance).

## 3. Dynamic Combat Music
- **`combat_intensity_theme.wav`**
  - **Purpose**: High-intensity battle layer that smoothly fades in when enemies engage and fades out upon victory.
  - **Style**: Fast cinematic taiko war drums, rhythmic staccato strings, aggressive brass hits.
